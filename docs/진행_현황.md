## 형기님이 직접 하셔야 하는 것

1. **Firebase 콘솔에서 Google Analytics 사용 설정** — 프로젝트 설정 → 통합. 이걸 안 하면 계측 코드가 조용히 비활성으로만 돕니다. **출시보다 먼저.**
2. **웹 재배포** — `npm run build && firebase deploy --only hosting`. 진행 표시 수정이 아직 서버에 없습니다.
3. **배포 후 GA 실시간 보고서에서 `study_start` 수신 확인** — 계측이 실제로 살아 있는지 보는 유일한 방법입니다.
4. **Play Console 계정 유형 확인** — 개인 계정이면 프로덕션 출시 전 **테스터 20명 × 12일 연속** 요건이 있습니다. 걸리면 일정이 2주 이상 밀립니다.
5. **스크린샷 7종 촬영** — 목록·캡션은 `AppStore_메타데이터.md`에 준비돼 있습니다. 라이트·다크 양쪽 확보 권장.
6. **App Privacy / 데이터 세이프티에 분석 항목 신고** — Firebase Analytics 연동에 따른 필수 신고. 항목은 `AppStore_메타데이터.md`·`docs/PlayStore_등록문.md` 참고.
7. **알림 감시 등록** — `cp ~/Desktop/hgmr/.claude/com.hgmr.inbox-watch.plist ~/Library/LaunchAgents/` 후 `launchctl load`.
