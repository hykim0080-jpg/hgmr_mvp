## 3. 교체하지 않은 것 — 판단 기준

> **기준 한 줄: 지금 살아 있는 기업·인물·브랜드·작품이면 교체하고, 역사·제도·일반 용어면 유지합니다.**

| 유지 | 예 | 이유 |
|---|---|---|
| **역사 인물** | 세종(업적·편찬) · 뉴턴(발견) | 교육적 맥락이고 브랜드와 정합적입니다 (P16과 같은 결) |
| **일반화된 약어** | AI · 5G · ICT | 보통명사처럼 쓰입니다 |
| **제도·정책 용어** | 분리공시제 · 감염병 대응 단계 「심각」 | 고유명사가 아닙니다 |
| **성씨 일반 지칭** | 「김씨 계보」(945) | 특정 인물이 아닙니다 |
| **기사체지만 익명·일반** | *"정부는 갯벌의 보전을 위해 개발을 제한하기로 했다"* | 자체 제작이 가능한 문장입니다. 문체만으로 교체하면 멀쩡한 문항까지 버립니다 |

⚠️ **「순응」(#994)** — *"곽 씨와 마주치면 그의 너무나도 당연한 고자세에…"* 고유명사는 아니지만 **소설 문체**입니다. 출처가 있다면 P45 대상이라 **별도 확인이 필요합니다.**

## 4. 자동 검증 — 71건 전부 통과

- ✅ 빈칸 `____` 존재
- ✅ **목표어 미노출** (P39)
- ✅ **`accepts` 유의어도 미노출**
- ✅ **고유명사 잔존 없음** (1~3차 탐지 패턴 전부 재적용)
- ✅ **기사 문체 잔존 없음** (3차 대상에 한해)
- ✅ **조사 받침 정합성** — 「감소/절감/축소/감축」처럼 받침이 섞인 문항에는 **을/를·이/가·은/는을 쓰지 않았습니다.** 「에」·「으로」·「하다/되다」 결합으로 처리

⚠️ **`npm run check-words`는 Code 쪽에서 한 번 더** 돌려주세요.

## 5. 덤으로 고친 것 — 「안정적」(#258)의 깨진 `accepts`

```
accepts: ["안정적", "확실한", "변함없는"]
기존:    삼성전자는 이번 투자가 … ____인 확보를 위한 것이라고 설명했다.
```

**「확실한」·「변함없는」은 이미 관형형**이라 「인」이 붙으면 *"확실한인 확보"*가 됩니다. **구조 자체가 성립하지 않는 문항**이었습니다.

```
교체:    부품 값이 오르는 것보다 무서운 것은 ____ 공급이 끊기는 일이다.
```

→ **안정적 공급 / 확실한 공급 / 변함없는 공급 — 셋 다 자연스럽습니다.** 고유명사 제거와 `accepts` 결함이 한 번에 풀렸습니다.

## 7. 여기까지가 한계입니다

3차까지 걸러도 **고유명사도 수치도 없이 기사에서 가져온 문장**은 남습니다. 문체만으로는 *"자체 제작한 딱딱한 문장"*과 구별되지 않고, 무리하게 걸러 내면 멀쩡한 문항까지 버립니다.

**남은 확인 방법은 두 가지뿐입니다.**

1. **원문 대조** — 의심 문항을 검색해 실제 기사와 맞춰 보는 것. 정확하지만 느립니다
2. **P42(자동 생성 + 확실한 검수)로 갈아 끼우기** — 출처를 따지는 대신 **새로 만드는 것**

> **2번이 낫다고 봅니다.** 어차피 콘텐츠 1,390개는 헤비 유저가 몇 주면 소진하고, 어휘 측정의 설득력도 규모가 상한입니다. **저작권 정리와 콘텐츠 확충이 같은 작업**이 됩니다.
