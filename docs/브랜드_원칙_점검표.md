## 0. 등급의 뜻 — **2026-08-05 변경**

> **현기님 판단:** *"모든 원칙은 타협 가능함. 다만 높은 등급일수록 더 강한 근거가 필요하고, 국소적인 부분에만 적용."*

초판은 A를 **「불변·협상 대상 아님」**으로 정의했습니다. **그게 아닙니다.**

| 등급 | 뜻 |
|---|---|
| **A** | 어기려면 **아주 강한 근거**가 필요. 어겨도 **그 자리에서만**, 전면 폐기는 안 됨 |
| **B** | 기본값. **근거가 있으면 바꿔도 됨** |
| **C** | 제안. **버려도 아무것도 안 무너짐** |

**「A니까 안 됩니다」는 더 이상 유효한 논거가 아닙니다.** A는 *"이걸 어기려면 이만큼 설명해야 한다"*는 문턱이지 금지가 아닙니다. 그리고 예외는 **국소적으로만** — 한 화면·한 기능에서 어기는 것과 원칙을 폐기하는 것은 다릅니다.

## 3. ⚠️ P29 · P32 변경의 구현 주의사항

두 항목은 **방향은 확정됐지만 그대로 넣으면 문제가 생깁니다.** Code에 🔴로 넘기면서 아래를 함께 적었습니다.

### P29 — 복습·재출제를 어휘 고도에 반영

**문제: 복습 단어는 이미 본 것이라 정답률이 높습니다.** 새 단어와 같은 K로 반영하면 **고도가 「얼마나 아는가」가 아니라 「얼마나 오래 썼는가」**가 됩니다. 오래 쓴 사람이 자동으로 높아집니다.

**해법 — 기억 단계만큼 난이도를 낮춰 계산합니다.**

```
b_복습 = wordDifficulty(w) − 40 × (기억 단계 s)
```

이미 세 번 맞힌 단어(`s=3`)를 또 맞히는 건 새 단어를 맞히는 것보다 쉽습니다. 난이도를 낮추면 **기대 확률이 올라가 delta가 작아지고**, 반대로 **복습에서 틀리면 delta가 커집니다** — 이게 이론적으로 맞고, *"아는 줄 알았는데 잊었다"*를 제대로 잡아냅니다.

**⚠️ 재출제(같은 세션 내 두 번째 시도)는 반영하면 이중 계수입니다.** 첫 시도 오답이 이미 반영됐는데 재도전 결과를 또 세면 같은 문항을 두 번 세는 셈입니다. **대신 재출제 정답 시 「첫 시도 오답으로 깎인 delta의 일부를 되돌리는」 방식**을 권합니다 — 벌하지 않는 원칙과도 맞습니다.

### P32 — 스트릭·EXP를 복습·신규 모드로도

- **스트릭은 「그날 학습했는가」의 기록**이므로 어떤 학습이든 오르는 게 맞습니다. 문제없습니다
- **EXP는 파밍 경로가 됩니다.** 미니게임이 EXP를 주면 그게 레벨업 최단경로가 됩니다
  → **조각과 같은 규칙**(하루 첫 판만 지급)을 EXP에도 적용하면 잠그지 않으면서 막힙니다

## 4. ⚠️ P38 · P42 변경의 파장 — 작지 않습니다

### P38 — 「유일하게」가 빠졌습니다

**말이 되는 단어가 여럿일 수 있다**면 유의어 설계의 전제가 바뀝니다.

- `accepts`를 **넓게 인정**해도 됩니다 (지금 「유의어 재도전」으로 튕기는 것 중 상당수가 그냥 정답이어도 됨)
- `nuance`의 역할이 *"이건 틀렸다"*에서 ***"이것도 되는데 더 잘 맞는 게 있다"***로 바뀝니다
- **「대조 예문」 방식**(`docs/유의어_뉘앙스_설계.md` 0-1절)은 오히려 더 잘 맞습니다 — 틀렸다고 말하지 않고 *"네 단어는 이 문장의 것"*을 보여주는 것이므로

### P42 — 자동 생성 + 확실한 검수

**콘텐츠 병목의 실마리입니다.** 단어 1,390개는 헤비 유저가 몇 주면 소진하고, 「내가 아는 어휘 N개」 같은 측정도 콘텐츠 규모가 상한이었습니다.

> **그리고 P45(예문 출처)와 맞물립니다.** 지금 예문 중 상당수가 기사 원문으로 보이는데, **자동 생성 예문은 출처 문제가 없습니다.** 재작성해야 할 문항을 자동 생성으로 갈아 끼우면 **두 문제가 한 번에 풀립니다.**

검수 기준은 P38·P39·P40이 그대로 적용됩니다. **`npm run check-words` 통과가 최소선**이고, 그 위에 사람 검수가 필요합니다.

## 5. 충돌 5 해소 — 칭호 개명안 (**v2**)

> **⚠️ 2026-08-05 재작성.** 초판은 「낱말 열 개 / 낱말 쉰 개 / 낱말 백쉰 개 / 사흘 내리 / 마루에 선 사람」이었는데, 현기님 지적대로 **순우리말을 억지로 밀어 어색했습니다.** 「백쉰」은 실생활에서 거의 안 쓰고, 「사흘 내리」는 부사가 홀로 서서 걸리고, 무엇보다 **셋은 칭호가 아니라 그냥 카운터**였습니다.

### 규칙 — 겹침을 원천 차단합니다

> **자동 칭호는 「사람」, 장착 칭호는 「행적」.**
> 자동은 *내가 무엇이 됐는가*(알망이 · 새싹 · 수집가 · 회원 · 후예 — 전부 사람), 장착은 *내가 무엇을 했는가*.
> **품사부터 다르므로 이름이 겹칠 수 없습니다.**

### 자동 칭호 — 그대로 둡니다

5단계 서사가 완결돼 있고(알망이 → 새싹 → 수집가 → 조선어학회 회원 → 세종의 후예), 홍보에서 주로 쓰입니다.

### 장착 칭호 — **4개만 바꿉니다**

| 조건 | 지금 | **제안** | |
|---|---|---|---|
| 기본 제공 | 🐣 아기 병아리 | 🐣 **첫걸음** | |

- **문제는 두 개(어휘 수집가·세종의 후예)였는데 초판은 여섯 개를 다 갈아엎었습니다.** 「작심삼일 극복」·「어휘 마스터」는 원래 이름이 더 잘 읽힙니다
