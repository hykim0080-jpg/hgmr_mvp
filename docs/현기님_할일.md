### 5. 연령 등급 설문 재응답

Apple이 등급 체계를 개편했고 **2026년 1월 31일 기한이 이미 지났습니다.** 미응답이면 제출이 막힙니다.

> App Store Connect → 앱 → **연령 등급 → 편집**

12개 항목 **응답안이 체크리스트 4절에 다 채워져 있습니다.** 그대로 옮겨 적으시면 됩니다. 예상 등급 4+.

## 🟡 판단이 필요한 것 — 제가 정할 수 없는 일

### 8. Apple 토큰 revoke를 위해 **Blaze 요금제로 올릴지**

Apple은 계정 삭제 시 토큰 폐기를 요구합니다. 그런데 Firebase JS SDK에는 이 API가 없어 **Cloud Functions가 필요**하고, 현재 Spark(무료) 요금제에서는 배포가 막힙니다.

| | 내용 |
|---|---|
| 지금 상태 | 계정·데이터 삭제 자체는 정상 동작. 토큰 폐기만 미구현 |
| Code 의견 | 이 항목만으로 거부되는 사례는 드묾. 지적받으면 그때 대응 권장 |
| 올릴 경우 | Blaze는 종량제. 이 규모면 실제 청구는 거의 0원이지만 **카드 등록이 필요**합니다 |

→ **지금은 그냥 제출하고, 지적받으면 그때 올리는 쪽**을 권합니다. 다르게 보시면 알려주세요.

### 9. Play Console 계정 유형 확인 — **일정을 좌우합니다**

> Play Console → 설정 → 개발자 계정 → 계정 세부정보

**개인 계정이면 프로덕션 출시 전 「테스터 20명 × 12일 연속 참여」 요건**이 붙습니다. 법인 계정은 면제입니다.

여기 걸리면 **일정이 2주 이상 밀립니다.** 나중에 알면 가장 아픈 항목이라 미리 확인하시길 권합니다. 걸린다면 테스터 모집을 지금부터 시작해야 합니다.
