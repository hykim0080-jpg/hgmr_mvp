### 5. 연령 등급 설문 재응답

Apple이 등급 체계를 개편했고 **2026년 1월 31일 기한이 이미 지났습니다.** 미응답이면 제출이 막힙니다.

```
App Store Connect → 앱 → 한글마루
  → 왼쪽 「일반」 → 「앱 정보」
      → 「연령 등급」 구역 → [설정] 또는 상단 [편집]
```

⚠️ **App Store Connect에 앱 레코드가 먼저 있어야 설문이 보입니다.** 없으면 「앱 → +」로 만드세요 (빌드 업로드 전에도 가능).

응답안은 **체크리스트 4절**에 다 채워져 있습니다. 예상 등급 **4+**. 두 가지만 미리 알아두세요.

- ⏰ **「소셜 미디어」 질문이 새로 생겼고 9월부터 필수**입니다. 우리는 사실대로 **「없음」** — 피드·좋아요·공유가 없습니다. **「있음」으로 답하면 스크린타임에서 소셜 미디어로 분류**되니 주의
- ⚠️ **「사용자 생성 콘텐츠」 한 칸만 판단이 필요합니다** — 오답 통계 패널 때문입니다. 체크리스트 **4-4절**에 선택지 셋과 제 권고를 적어뒀습니다

### 8. Apple 토큰 revoke를 위해 **Blaze 요금제로 올릴지**

Apple은 계정 삭제 시 토큰 폐기를 요구합니다. 그런데 Firebase JS SDK에는 이 API가 없어 **Cloud Functions가 필요**하고, 현재 Spark(무료) 요금제에서는 배포가 막힙니다.

| | 내용 |
|---|---|
| 지금 상태 | 계정·데이터 삭제 자체는 정상 동작. 토큰 폐기만 미구현 |
| Code 의견 | 이 항목만으로 거부되는 사례는 드묾. 지적받으면 그때 대응 권장 |
| 올릴 경우 | Blaze는 종량제. 이 규모면 실제 청구는 거의 0원이지만 **카드 등록이 필요**합니다 |

→ **지금은 그냥 제출하고, 지적받으면 그때 올리는 쪽**을 권합니다. 다르게 보시면 알려주세요.

### 9. Play Console — **지금 시작하세요** (테스터는 나중에)

> **2026-08-19 정정**: 제가 「20명 × 12일」로 잘못 적어 왔습니다. 실제 요건은 **12명 × 14일**입니다.

#### 먼저 확인 — 요건이 아예 없을 수도 있습니다

> Play Console → 설정 → 개발자 계정 → 계정 세부정보

**2023년 11월 13일 이전에 만든 개인 계정**이면 이 요건이 **적용되지 않습니다.** 법인 계정도 면제입니다. 여기서 끝날 수도 있으니 이것부터 보세요.

#### 요건이 있다면 — 테스터 없이 먼저 등록하는 게 맞습니다

**14일 카운트는 「테스터가 옵트인한 시점」부터 셉니다.** 트랙을 미리 열어두는 것만으로는 시계가 가지 않으므로 **손해가 전혀 없습니다.** 오히려 —

- **등록을 해야 모집할 링크가 생깁니다.** 순서가 반대일 수 없습니다
- 스토어 등록정보·콘텐츠 등급·데이터 안전 설문은 시간이 걸리는데, 이걸 미리 끝내 두면 테스터가 모이는 즉시 시작됩니다

#### 테스터 모으는 요령

- **12명을 모아서 한꺼번에 시작하세요.** 「연속 14일」이라 중간에 나간 사람은 안 쳐줍니다. 한두 명씩 넣으면 이탈만 쌓입니다
- **구글 계정 이메일**이 필요합니다. 아이폰 사용자도 구글 계정만 있으면 명단에 넣을 수 있지만, **안드로이드 기기가 있어야 실제 설치**가 됩니다
- **Google 그룹스를 쓰면 이메일을 하나하나 안 받아도 됩니다** — 그룹 하나를 테스터로 등록하고, 사람들에게 그룹 가입 링크만 보내면 됩니다
- 문서상 요건은 「참여 선택 상태 유지」지만, **설치까지 부탁하는 편이 안전**합니다
