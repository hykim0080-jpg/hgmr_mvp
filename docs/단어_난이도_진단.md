# 단어 난이도·레벨 진단 리포트

> 작성: 2026-07-30 · Claude Code
> 근거: `words.json` 1,390개 전수 + Firestore `word_stats` 실측 응답 2,438회 + `meta/item_ratings`

---

## 요약

| 문제 | 판정 |
|---|---|
| ① 레벨 분포 편중 (Lv1 774 · Lv2 451 · **Lv3 165**) | 사실 — 상위 난이도 콘텐츠 부족 |
| ② **레벨이 실제 난이도와 불일치** | **사실이며, ①보다 심각.** 실측상 레벨과 정답률이 역전 |
| ③ 원인 | 수능 단어 722개 **일괄 도입 시 대부분 Lv1로 기본 배정**된 것으로 보임 |

**핵심**: 레벨은 표시용 라벨이 아니라 **어휘 고도 측정의 입력값**이다(`wordDifficulty()`). 레벨이 틀리면 사용자 실력 추정이 왜곡된다.

## 1. 실측 — 레벨과 정답률이 역전되어 있다

응답 5회 이상인 단어 166개, 총 1,599회 응답 기준.

| 레벨 | 단어 | 응답 | 정답률 |
|---|---|---|---|
| Lv1 | 66개 | 621회 | **45.6%** |
| Lv2 | 51개 | 447회 | 49.0% |
| Lv3 | 49개 | 531회 | **58.0%** |

레벨이 올라갈수록 정답률이 **높아진다.** 정상이라면 반대여야 한다.

> ⚠️ **해석 주의 — 선택 편향**: 앱은 적응형 출제(P≈0.65 밴드)라 어려운 단어일수록 실력 높은 사용자에게 배정된다. 따라서 이 역전 폭 전부가 오배정 탓은 아니다.
> 다만 적응형이 정상 작동한다면 레벨과 무관하게 정답률이 **65% 근처로 수렴**해야 하는데, Lv1만 45.6%로 크게 벗어난다. 즉 **Lv1에 실제로 어려운 단어가 섞여 있다**는 신호로 읽는 것이 타당하다.

## 3. 원인 추정 — 일괄 도입 시 기본 레벨 배정

태그별 레벨 분포를 보면 출처가 갈린다.

| 출처 | 총계 | Lv1 | Lv2 | Lv3 | Lv1 비율 |
|---|---|---|---|---|---|
| **`수능`** (일괄 도입) | 722 | 566 | 111 | 45 | **78%** |
| 수능 외 (수작업 큐레이션) | 668 | 208 | 340 | 120 | 31% |

수작업으로 만든 단어는 Lv2가 가장 두터운 정상 분포인 반면, **일괄 도입분은 78%가 Lv1**에 몰려 있다. 커밋 이력(`81f5e08 수능단어` → `3cbe493 수능 단어 662개 추가`)과도 맞는다.

즉 **레벨 편중과 오배정은 같은 뿌리**다. Lv1 774개 중 566개가 이 경로에서 왔다.

## 4. 왜 중요한가 — 어휘 고도 측정이 왜곡된다

`index.html`의 `wordDifficulty()`는 레벨을 난이도 점수로 직접 환산한다.

```
기초 태그 → b = 1000
Lv1      → b = 1250
Lv2      → b = 1450
Lv3      → b = 1650
```

이 `b`가 Elo 기대승률 `P(정답)` 계산에 들어가고, 그 결과가 **사용자의 어휘 고도(θ)** 를 올리거나 내린다.

따라서 `주체`(실제 정답률 0%)를 b=1250으로 두면:
- 사용자가 틀려도 "쉬운 걸 틀렸다"고 판정 → **고도가 과하게 깎임**
- 반대로 `모순`(정답률 100%)은 b=1650이라 맞히면 **고도가 과하게 오름**

배치고사의 고정 앵커도 난이도 백분위로 뽑으므로 같은 왜곡을 받는다.

## 5. 권고

### 즉시 (출시 전, 저비용)

**A. 실측 기반 우선 교정 — 위 2절의 37개 단어**
n≥5로 신호가 뚜렷한 것만 손보면 된다. Lv1 저정답률 23개는 Lv2~3으로, Lv3 고정답률 14개는 Lv2로.
→ 이 정도만으로도 `wordDifficulty` 왜곡의 큰 부분이 줄어든다.

**B. 자동 보정 장치는 이미 있다 — 켜져 있는지 확인만**
`meta/item_ratings`가 단어별 난이도를 실사용으로 자동 보정한다(`b += itemRatingDelta`). 다만 현재 **보정치 범위가 −2~+4로 사실상 0**이다. 데이터가 쌓이면 스스로 교정되므로, 사용자 유입 후 이 값의 분포를 다시 볼 것.

### 중기 (사용자 유입 후)

**C. 레벨을 실측에서 역산**
단어별 응답이 n≥30 정도 쌓이면 정답률로 레벨을 재배정하는 것이 수작업보다 정확하다. 기준 예: 정답률 70%↑ → Lv1, 45~70% → Lv2, 45%↓ → Lv3.

**D. 레벨 분포 목표**
현재 Lv1 56% / Lv2 32% / Lv3 12%. C를 적용하면 자연히 완만해지지만, 상위 티어(어휘 고도 능선~마루) 콘텐츠 소진을 막으려면 **Lv3를 300개 이상**으로 늘리는 것이 바람직하다.

### 하지 말 것

- **음절 수·한자어 접미사 같은 형태 규칙으로 일괄 재배정하지 말 것.** 검증해 보니 신호가 약했다 (Lv1 774개 중 추상 접미사형은 14개뿐인데, 실제 어려운 Lv1 단어는 `주체`·`현상`·`구실`처럼 짧고 평범한 형태다). 형태가 아니라 **의미의 추상도**가 난이도를 만든다.
