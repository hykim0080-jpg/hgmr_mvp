# 필라 ① 10초 어휘력 테스트 (40% · 총 3개)

> **포맷**: 1장 = 빈칸 문장 + 초성 힌트 / 2장 = 정답 + 뜻풀이 / 3장 = 앱 유도
> **캡션 규칙**: 정답을 캡션에 쓰지 않는다. "정답은 댓글로" → 댓글 수가 곧 도달로 이어진다.

## 1주 화 — #01 「환희」

**슬라이드 1**
```
빈칸에 들어갈 단어는?

우승이 확정되는 순간 선수들은
서로 얼싸안고 ____의 함성을 질렀다.

힌트:  ㅎ ㅇ  (2글자)
```

**슬라이드 2**
```
정답: 환희

매우 기뻐함. 또는 큰 기쁨.

'기쁨'보다 크고, '희열'보다 밖으로 터져 나오는 감정.
```

**슬라이드 3**
```
이런 문제 1,390개
한글마루
```

**캡션**
> 10초 안에 떠올랐나요?
> '기쁨'은 알아도 '환희'는 잘 안 나옵니다. 아는 단어와 쓰는 단어가 다르기 때문이에요.
>
> 정답은 댓글에 적어 주세요 👇
> 저장해 두고 내일 다시 떠올려 보면 확실히 남습니다.

# 필라 ② 헷갈리는 단어 대결 (25% · 총 2개)

> **포맷**: 카드뉴스 4~5장. 1장 = 대결 구도 / 2~3장 = 각각의 뜻 / 4장 = 한 문장 구분법 / 5장 = 앱 유도
> **핵심**: 마지막에 반드시 **외우기 쉬운 한 줄 공식**을 준다. 이게 저장률을 만든다.

## 1주 목 — #04 「감소 vs 절감 vs 축소」

앱에서 실제로 세 단어를 서로의 유의어로 인정합니다 — 그만큼 헷갈린다는 뜻입니다.

**슬라이드 1**
```
셋 다 '줄이는' 건데
뭐가 다를까?

감소 · 절감 · 축소
```

**슬라이드 2~4**
```
감소 — 저절로 줄어듦
"방문자 수가 감소했다"  (내 의지 아님)

절감 — 아껴서 덜 씀
"비용을 절감했다"  (돈·자원에 씀)

축소 — 규모를 작게 만듦
"사업을 축소했다"  (내가 줄인 것)
```

**슬라이드 5**
```
한 줄 공식

감소는 '일어나는 것'
절감은 '아끼는 것'
축소는 '줄이는 것'
```

**캡션**
> 보고서에서 이 셋을 바꿔 쓰면 의미가 완전히 달라집니다.
> "비용이 감소했다"와 "비용을 절감했다"는 다른 말이에요. 앞은 운, 뒤는 성과.
>
> 저장해 두고 보고서 쓸 때 꺼내 보세요 📌

## 2주 목 — #05 「자책 vs 후회 vs 수치심」

**슬라이드 1**
```
잘못한 뒤 드는 감정,
셋 중 뭐였나요?

자책 · 후회 · 수치심
```

**슬라이드 2~4**
```
후회 — 이전의 잘못을 깨닫고 뉘우침
→ 행동을 향한다. "그러지 말걸"

자책 — 자신의 잘못에 대해 스스로를 책망함
→ 나를 향한다. "내가 문제야"

수치심 — 스스로 떳떳하지 못하여 느끼는 부끄러움
→ 남의 시선을 향한다. "들켰어"
```

**슬라이드 5**
```
한 줄 공식

후회는 행동을,
자책은 나를,
수치심은 남의 눈을 본다.
```

**캡션**
> 심리학에서 후회는 성장으로 이어지지만 자책은 그렇지 않다고 봅니다. 향하는 곳이 다르기 때문이에요.
> 감정을 정확히 부르는 것만으로 다뤄지는 방식이 달라집니다.
>
> 요즘 어느 쪽이 많으셨나요? 댓글로 👇

# 필라 ③ 하랑이 캐릭터 (20% · 총 2개)

> **포맷**: 단컷 또는 2컷. 말풍선 중심, 텍스트 최소.
> **주의**: 유아용 과잉 애교 금지. 담백한 반말.

## 1주 토 — #06 하랑이 소개

**이미지**: 기본 포즈(조각 안기) 하랑이 + 말풍선

```
안녕, 나는 하랑이.

'하랑'은 하늘 + 랑(함께).
하늘처럼 넓은 어휘의 세계를
너랑 같이 오르는 친구라는 뜻이야.
```

**캡션**
> 한글마루에는 하랑이가 삽니다. 초록 목도리를 두른 하프물범이에요.
> 맞히면 박수를 치고, 틀리면 같이 아쉬워합니다. 채점하지는 않아요.
>
> 앞으로 여기서 자주 만나요 🦭

---

## 2주 토 — #07 "틀려도 안 내려가"

**2컷 만화**

```
[1컷] 눈물 포즈 하랑이
      "또 틀렸어…"

[2컷] 기본 포즈 하랑이 + 산 그래픽
      "괜찮아. 칭호는 안 뺏어.
       최고 기록도 그대로 남아."
```

**캡션**
> 한글마루를 만들면서 정한 원칙이 하나 있습니다. **틀리는 걸 벌하지 않는다.**
>
> 하트도 순위도 없습니다. 한 번 오른 칭호는 안 뺏고, 최고 기록도 그대로 둡니다.
> 해발 숫자만 내 실력을 정직하게 따라갑니다 — 하루에 조금씩만요.
> 벌주지 않으면서도 거짓말은 하지 않는 방법을 오래 고민했습니다.
>
> 어제보다 딱 한 뼘.
