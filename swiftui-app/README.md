# 한글마루 SwiftUI 버전

기존 Capacitor(웹뷰) 앱과 **완전히 분리된** 네이티브 SwiftUI 구현입니다. UI/UX 평가용으로, 웹앱(`www/index.html`)의 화면·로직 스펙을 추출해 동일하게 재현했습니다.

## 실행 방법

```
open swiftui-app/HangulMaru.xcodeproj
```
Xcode에서 iPhone 시뮬레이터를 선택하고 ▶ 실행. (별도 서명 없이 시뮬레이터에서 바로 실행됩니다)

## 구현 범위

### 화면
- **웰컴 화면** — 민트 배경, 만화풍 말풍선, 깜빡이는 하랑이, 버튼 3종, 스플래시 650ms, 재접속 시 "화면을 터치하여 시작하기" 게이트
- **이메일 로그인/회원가입** — 모드 전환, 검증 문구, 비밀번호 재설정, 오류 토스트 전부 원본 문구
- **홈 화면** — breathe 아바타 + Lv 배지, 주제 칩, 칭호·어휘 고도 칩, 통계 카드 4종, EXP 바, 복습 안내, 관리자 버튼
- **퀴즈 화면** — 진행바, 신고 버튼, 상황 배지(복습/재도전/유의어 재도전), 빈칸 문장(용언 어미 분리), Lv 뜻풀이, 정답 보기/제출, 하랑이 컴패니언(박수/부들부들/말풍선/조각 스프라이트), 오답 shake
- **자모 커스텀 키보드** — 빙하 테마(라이트/다크), 두벌식 배열, 시프트 쌍자음(1회용), 백스페이스 롱프레스 반복, 키 팝 프리뷰, 햅틱, 한글 조합 오토마타(겹모음·겹받침 결합/분해)
- **오답 통계 패널** — "사람들은 이 문장을 어떻게 완성했을까요?" 상위 5개 분포 + 정답/유의어/오답 배지
- **결과 화면** — 파티 하랑이(고깔+콘페티 3프레임), 2×2 통계, 어휘 지수 행
- **모달 13종** — 프로필 설정(포즈 4종·목도리 5색·닉네임·칭호 6종 잠금·단어 수 10~50), 주제 선택(6종), 출석 달력(연속 연결 바), 낱말카드(4열+상세), 학습 분석(요약 칩 6종+차트 3종), 업적(5종), 종료/로그아웃/이어하기 확인, 단어 신고(사유 5종), 배치고사 안내/결과, 어휘 고도 안내(티어 5단계+산 일러스트), 관리자 검수 패널(간이)
- **다크모드** — 시스템 연동, 웹앱 CSS 변수의 다크 팔레트 전체 대응

### 로직 (웹앱 수식 그대로)
- **어휘 고도** — Elo 기반 능력 추정: 난이도 `b`(레벨·문장 길이·유의어 수·태그·전역 보정), `expectedP`, K 감쇠(32→16→8), peak 절대 하락 없음, 티어 5단계
- **배치고사** — 최대 20문항·15문항 수렴 조기 종료(최근 6개 폭 ≤100), 문항당 재입력 3회, K=max(40, 120−6n), 완료 시 지혜 조각 +15
- **세션 편성** — 복습 쿼터 40%(오답 우선), 주제 65% 비중, 85% 규칙 P-밴드 샘플링(적정 60%/도전 25%/자신감), SRS 간격 1→3→7→14→30일
- **채점** — 어간/기본형 완전 정답 → 유의어(accepts) → 오답 순서, 오답·정답보기 시 3~6문제 뒤 재출제, 유의어 첫 정답 시 재도전 문항 삽입
- **보상** — 정답 +1 지혜 조각, 3연속 보너스 +1, 첫 시도 정답 +20 EXP, 200 EXP당 레벨업
- **스트릭/출석** — 세션 완료 시 갱신, 앱 시작 시 깨짐 검증, 학습일 기반 출석 달력
- **이어하기** — 진행 중 세션 저장·복원 ("풀던 문제가 있어요!")

## 원본과 다른 점 (UI/UX 평가용 대체)
- **Firebase → 로컬 저장** — 인증/데이터가 기기 내 JSON으로 저장됩니다 (이메일 가입·로그인 흐름은 동일하게 동작, Google 로그인은 데모 계정 진입)
- **오답 통계** — 전 유저 공용 `word_stats` 대신 로컬 누적 데이터 사용
- **Jua 폰트** — 라이선스 확인 전까지 시스템 라운드 헤비체로 대체
- **관리자 패널** — 신고 열람·처리 완료만 (인라인 수정·JSON 내보내기 미구현)

## 테스트용 실행 옵션
환경변수 `HM_AUTO`로 특정 상태 진입: `home`(익명 로그인+홈) / `quiz`(세션 시작) / `answered`(정답 제출 상태) / `placement`(배치고사) / `result`(결과 화면)
