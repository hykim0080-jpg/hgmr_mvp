### 🔴 Problem — 풀고자 하는 문제

AI 시대에 언어 구사력이 핵심 역량으로 부상한 반면, 현대인의 어휘력은 숏폼 미디어로 급격히 저하되고 있습니다.

- 서울 고1 10명 중 3명 기초 문해력 미달

- KAIST에서도 어휘 소통 병목 직접 체감

### 🔵 Solution — 나의 솔루션

한글마루: 한국어 어휘 성장 플랫폼

- 자모 직접 타이핑 빈칸채우기 → 능동적 회상
- 유저 간 실시간 오답 통계 → 메타인지 강화
- 수능·학술·격식·감정별 큐레이션 세션
- iOS · Android · 웹 MVP 개발 완료 (배포 준비 중)

### 🟢 AI 활용 역량 — AI 도메인 전문성 및 활용 계획

AI 에이전트를 공동 개발자로 활용한 1인 풀스택 구현

- AI 에이전트(Claude Code)로 iOS·Android·웹 전 과정 개발

## Slide 3 — Problem 1/2 (시대적 배경 · 시장 현황)

### ① 시대적 배경 — AI가 언어력 격차를 심화시킨다

AI 보편화로 단순 실행력은 자동화되는 반면, 결과를 꿰뚫는 언어 구사력과 인문학적 사고력이 핵심 역량으로 재부상합니다. AI와 소통하는 프롬프트 작성에서도 의도를 정확히 언어화하는 능력은 기술적 기량이 됩니다. 인공지능은 매일 수십억 개의 단어를 학습하며 똑똑해지는데, 우리는 '심심한 사과'의 뜻을 몰라 검색창을 헤매고 있습니다.

### ② 시장 현황 — 어휘력 위기는 수치로 증명된다

## Slide 4 — Problem 2/2 (시장 공백 분석)

### ③ 시장 공백 — 외국어는 넘치고, 모국어 어휘 전문 플랫폼은 전무하다

| 구분 | 외국어 학습 시장 (영어) | 한국어 어휘 학습 (현황) |
|---|---|---|
| 대표 서비스 | Duolingo, Quizlet, 말해보카, 클래스101 등 수백 개 | 전무에 가까움 (아래 참고) |
| 학습 방식 | 문맥 기반, 게이미피케이션, SRS 알고리즘 | 없음 |
| 개인화 | 오답 분석, 맞춤형 복습 스케줄 | 없음 |
| 시장 규모 | 국내 영어교육 시장 4조 원+ | 미개척 블루오션 |
| 잠재 수요 | — | 아래 참고 |

### 한국어 어휘 관련 서비스 현황 (조사 결과)

실질적인 경쟁자는 없으나 인접 서비스 존재:

| 서비스 | 특징 | 한글마루와의 차이 |
|---|---|---|
| 표준국어대사전 앱 (국립국어원) | 공식 사전, 검색 기능 | 퀴즈·학습 기능 없음 |
| 뽀득국어 | 수능 국어 문제풀이 | 어휘가 아닌 독해·문법 중심 |
| EBS 국어영역 | 수능 대비 문제 풀이 | 시험 대비용, 일상 어휘 없음 |
| 네이버/다음 사전 | 단어 검색 | 능동적 학습 기능 없음 |

→ **맥락 기반 퀴즈 + 게이미피케이션 + 개인화 복습을 결합한 한국어 어휘 전문 앱은 현재 국내에 존재하지 않음**

### 잠재 수요 (수정 확장)

- **직접 수요:** 생활 문해력에 어려움을 겪는 성인 735만 명 (한국교육개발원)
- **확장 수요:** 어휘력 향상 필요성을 느끼는 고등학생(수능), 대학생(논문·발표), 직장인(격식·소통) — 실질적 잠재 고객은 수천만 명 규모
- **AI 시대 신규 수요:** 프롬프트 작성, AI 도구 활용 능력과 어휘력이 직결되면서 30·40대 직장인의 언어 능력 향상 수요 급증

> **[수정 사항]**  
> - 말해보카를 외국어 학습 서비스 목록에 추가  
> - 한국어 어휘 학습 서비스 조사 결과 별도 표로 정리  
> - 잠재 수요를 735만 명 이상으로 확장 서술

## Slide 5 — Solution 1/2 (3가지 차별화 솔루션)

### ① 원어민 맞춤형 능동적 학습 — 직접 타이핑하는 빈칸채우기

이미 문장 구조를 이해하는 원어민에게 선택지 암기는 불필요합니다. 커스텀 한글 자모 키보드로 직접 타이핑하는 능동적 회상(Active Recall)으로 장기 기억 효율을 높입니다. 정답을 맞힐 때마다 쌓이는 경험치(Lv.)와 연속 학습일 시스템으로, 지루한 국어 공부가 아닌 게임 같은 즐거운 루틴을 만듭니다.

### ② 메타인지 강화 — 유저 간 실시간 오답 통계

정답 제출 후 단순히 나의 정오답 여부만이 아니라 다른 유저들이 입력한 정오답 및 유의어 비율을 실시간으로 보여줍니다. '내가 빠진 함정에 남들도 똑같이 빠졌다'는 데이터를 통해 학습 좌절감 대신 함께 성장하는 강력한 연결감과 메타인지를 동시에 제공합니다.

### ③ 생애주기별 맞춤 큐레이션 — 지금 필요한 어휘 세션 직접 선택

수능 고득점 목표 고등학생(필수·심화 수능 어휘 726개), 논문·발표 대학생(학술·논리 어휘), 세대 간 소통 어려움 직장인(격식·비즈니스 어휘), 감정 표현을 원하는 성인(감정·심리 어휘). 유저가 현재 가장 필요한 어휘를 직접 선택하여 즉각적인 효과를 제공합니다.

## Slide 7 — AI 활용 역량 1/2 (현재 구현된 파이프라인)

### AI Agent 파이프라인 흐름

```
AI 에이전트(Claude Code)  →  풀스택 개발  →  관리자 검수(admin.html)
                                                      ↓
                                          Firestore (word_edits/deletions)
                                                      ↓
                                          sync_words.js (자동 동기화)
                                                      ↓
                                          iOS · Android · 웹 앱 반영
```

### 상세 구현 내용

| AI 활용 영역 | 현재 구현 완료 내용 | 성과 |
|---|---|---|
| 1인 풀스택 개발 | AI 에이전트(Claude Code)를 공동 개발자로 활용하여 iOS·Android·웹 전 과정 구현 | 1인이 멀티플랫폼 MVP 완성 |
| 콘텐츠 구축 | 수능 어휘 662개 예문 자동 추출 스크립트 + 관리자 인라인 편집 검수 | 1,189개 큐레이션 데이터 구축 |
| 품질 관리 자동화 | 관리자 검수 시스템(admin.html) + Firestore 실시간 반영 | '수정 필요' 단어 자동 제외 |
| 데이터 파이프라인 | sync_words.js: Firestore → words.json 자동 동기화 | 검수 즉시 앱 자동 반영 |

## Slide 8 — AI 활용 역량 2/2 (경쟁 우위 & 향후 로드맵)

### AI가 창출하는 핵심 경쟁 우위

**1. 1인 개발 한계 돌파 — AI 에이전트가 가능하게 한 것**

- 기획·디자인·iOS 개발·Android 개발·웹 개발·백엔드·데이터 파이프라인을 1인이 구현
- AI 에이전트 없이는 동일한 속도와 범위로 구현 불가능
- OverEdge 프로그램이 지향하는 'AI = 공동창업자' 모델의 실증

**2. 콘텐츠 생산 속도**

- 새로운 주제 단어팩 추가 시 기존 방식(편집팀 운영): 수개월 소요
- 현재 파이프라인(스크립트 + 검수 시스템): 수일 내 완료
- 시장 대응 속도 자체가 경쟁 우위

### 향후 AI 활용 확장 계획

**단기 (2026 Q3~Q4):**

- Claude/Gemini API 연동으로 단어 예문 자동 생성 기능 구현
- 학습자 오답 패턴 분석 → 맞춤형 복습 세션 자동 생성
- 망각 곡선 연동 AI 푸시 알림

**중기:**

- AI 학습 코치: 오늘 이 단어를 복습해야 하는 이유 맥락 설명
- 단어팩 콘텐츠 규모 대폭 확장

> **[수정 사항]**  
> - "동일 파이프라인으로 타 언어 어휘팩 → 글로벌 진출" 항목 제거  
>   (현재 서비스 성격과 맞지 않음. 한국어 어휘 서비스로서의 정체성 강화가 우선)  
> - 글로벌 확장성보다 1인 개발 한계 돌파와 AI 개발 파트너십을 핵심으로 재구성
